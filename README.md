# HTML001 - AGI Chronicles Explorer

Interactive reference website based on *The AGI Chronicles* by Kevin Roose.

## Purpose

The explorer organizes the people, companies, schools, projects, and relationships relevant to the development of artificial intelligence discussed in or associated with the book.

## Project started

November 15, 2026

## File naming

HTML001 - AGI Chronicles Explorer - YYYYMMDD - HHMM - vXXX.html

## Versioning

- Each development iteration receives a new timestamp and incremented version number.
- Previous versions are retained in the repository for history.
- The newest approved version is the current working version.
- GitHub commit history provides an additional record of changes.
